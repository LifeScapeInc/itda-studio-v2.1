# 이미지 생성 프리셋 분해 논의

기록일은 2026-11-19이다. 콘텐츠 세트와 앵글 변주의 기존 동작 분석, 용도·구도·비율로 분해하는 제안까지 정리한다. 옵션명은 분류 당시 표현을 사용한다. 아래 분류는 설계 제안이며 구현 여부를 뜻하지 않는다.

## 기존 콘텐츠 세트

자유 생성을 제외한 콘텐츠 세트는 상세페이지 4컷, SNS 4컷, 광고 3컷, 룩북 4컷이다. 각 컷은 서로 다른 프롬프트와 비율을 생성 요청에 전달한다.

| 세트 | 컷 | 비율 | 요청 크기 | 프롬프트 의도 |
|---|---|---|---|---|
| 상세페이지 | 메인 히어로 | 3:4 | 1152×1536 | 제품 소개의 대표 이미지 |
| 상세페이지 | 45도 컷 | 1:1 | 1024×1024 | 형태와 깊이가 드러나는 사선 구도 |
| 상세페이지 | 디테일 컷 | 1:1 | 1024×1024 | 소재와 제작 디테일 클로즈업 |
| 상세페이지 | 공간 연출 컷 | 16:9 | 2048×1152 | 실제 방에 놓인 제품의 크기감과 공간 맥락 |
| SNS | 피드 | 1:1 | 1024×1024 | 스크롤 중 시선을 끄는 정사각 이미지 |
| SNS | 세로 피드 | 4:5 | 1024×1280 | 세로형 라이프스타일 이미지 |
| SNS | 스토리 | 9:16 | 1152×2048 | 화면 가장자리까지 채우는 스토리 이미지 |
| SNS | 광고용 | 1:1 | 1024×1024 | 광고 문구를 얹을 여백이 있는 이미지 |
| 광고 | 배너 와이드 | 16:9 | 2048×1152 | 제품을 한쪽에 두고 옆에 카피 공간 확보 |
| 광고 | 배너 세로 | 9:16 | 1152×2048 | 문구를 배치할 안전 영역 확보 |
| 광고 | 썸네일 | 1:1 | 1024×1024 | 작은 크기에서도 제품을 알아볼 수 있는 이미지 |
| 룩북 | 전면 | 3:4 | 1152×1536 | 깔끔한 정면 이미지 |
| 룩북 | 사이드 | 3:4 | 1152×1536 | 제품 측면 이미지 |
| 룩북 | 라이프스타일 | 3:4 | 1152×1536 | 스타일링한 생활 장면 |
| 룩북 | 클로즈업 | 3:4 | 1152×1536 | 표면 질감 클로즈업 |

세트별 공통 역할은 상세페이지의 온라인 가구 스토어 제품 사진가, SNS의 브랜드 소셜 콘텐츠 디자이너, 광고의 유료 광고 아트 디렉터, 룩북의 브랜드 룩북 사진가이다. 룩북은 컷 전체의 일관된 시각적 톤을 지시한다.

기존 콘텐츠 세트의 최종 프롬프트에는 역할과 목적, 제품 보존 조건, 레퍼런스 적용 방식, 컷별 의도, 조명·분위기·소품, 사용자 입력, 사실적인 표현 지시가 조합된다. 기존 코드에서 레퍼런스가 없을 때는 제품 주변에 새 공간을 만드는 지시가 사용된다. 이후 분해 제안에서는 입력을 완성된 공간 사진으로 해석하도록 전제를 변경했다.

## 기존 앵글 변주

다섯 변주는 공통으로 첫 번째 이미지를 완성된 실제 방 사진으로 취급한다. 같은 촬영을 이어가는 사진가가 카메라 위치를 옮겨 재촬영하며, 방과 사물을 동일하게 유지한다. 새 프레임 밖으로 나간 요소는 생략하고 대체물을 만들지 않도록 지시한다.

| 변주 | 컷 지시 | 구도와 촬영 기법 |
|---|---|---|
| 고감도 클로즈업 | 제품에 가까이 다가가 프레임을 채움 | 눈높이 정면, 매크로 촬영, 매우 얕은 심도, 소재 표면에 초점, 나뭇결·직조·마감의 촉각적 표현 |
| 리버스 앵글 | 방 반대편에서 원래 카메라 방향으로 촬영 | 45도 사선, 85–135mm 망원, 원근 압축, 평행한 수직선, 부드러운 배경 흐림 |
| 에디토리얼 텔레포토 | 뒤로 물러나 눈높이 정면에서 촬영 | 85–135mm 망원, 원근 압축, 평행한 수직선, 부드러운 배경 흐림 |
| 로우앵글 아키텍처럴 | 바닥 가까이에서 살짝 위로 촬영 | 틸트시프트 건축 렌즈, 벽 수직선 유지, 키스톤 왜곡 억제, 전후방 선명도, 정교한 인테리어 매거진 프레이밍 |
| 와이드 환경샷 | 뒤로 물러나 방 전체를 담음 | 넉넉한 여백, 서 있는 높이에서 24–35mm 광각 촬영, 공간 속 제품 배치 맥락, 왜곡 보정 |

리버스와 에디토리얼 텔레포토는 망원 촬영 기법 문구가 같다. 카메라의 이동 위치와 바라보는 방향이 다르다.

앵글 변주의 비율 값은 모두 `original`이며 UI는 원본 비율로 표시한다. 서버는 이를 고정 크기 1536×1024, 즉 3:2로 매핑한다. 실제 출력 이미지는 이번 분석에서 생성하거나 검증하지 않았다.

## 새 생성 구조의 전제

- 별도 레퍼런스 없이 첫 번째 입력 이미지를 완성된 공간 사진으로 사용한다.
- 제품과 공간의 동일성을 유지하면서 선택한 용도·구도·비율을 적용한다.
- 용도는 이미지 자체의 쓰임, 구도는 이미지 안에서 피사체를 바라보고 배치하는 방식, 비율은 가로세로 비율을 뜻한다.
- 기존 프리셋은 이 세 속성을 조합한 이미지 템플릿 몇 개를 미리 묶은 것으로 해석한다.
- 예를 들어 SNS 광고용은 `배너 × 기본 × 1:1`로 표현한다.

## 용도 후보 4개

| 값 | 공통 지시 | 통합 대상 |
|---|---|---|
| 일반 이미지 | 제품이나 공간을 보여주는 사진으로 구성 | 상세페이지 일반 컷, SNS 피드와 세로 피드, 룩북, 앵글 변주 |
| 배너 | 문구를 얹을 여백 확보. 가로형은 제품 옆, 세로형은 문구 안전 영역을 우선 | SNS 광고용, 가로·세로 광고 배너 |
| 썸네일 | 작은 크기에서도 실루엣과 특징을 식별할 수 있게 구성 | 광고 썸네일 |
| 스토리 | 화면 가장자리까지 이미지를 채움 | SNS 스토리 |

메인 히어로와 SNS 피드는 대표 이미지와 시선 유도라는 목표가 있지만 촬영 지시는 구체적이지 않아 일반 이미지로 통합하는 안이다. 스토리는 9:16 비율에 더해 화면을 가득 채우는 지시가 있어 별도 용도로 유지했다.

## 구도 후보 7개

| 값 | 공통 지시 | 통합 대상 |
|---|---|---|
| 기본 | 제품 중심의 안정적인 프레이밍. 정면과 눈높이를 기본값으로 설정 | 메인 히어로, SNS 피드·스토리·광고용, 광고 배너·썸네일, 룩북 전면, 에디토리얼 텔레포토 |
| 사선 | 사선에서 형태와 깊이감을 드러냄 | 상세페이지 45도 컷 |
| 사이드 | 제품 측면 실루엣을 보여줌 | 룩북 사이드 |
| 디테일 | 소재와 마감이 프레임을 채우도록 가까이 접근 | 상세페이지 디테일, 룩북 클로즈업, 고감도 클로즈업 |
| 공간 포함 | 주변 공간과 제품을 함께 담아 배치 맥락과 크기감을 보여줌 | 상세페이지 공간 연출, SNS 세로 피드, 룩북 라이프스타일, 와이드 환경샷 |
| 리버스 | 방 반대편에서 원래 카메라 방향으로 촬영 | 리버스 앵글 |
| 로우앵글 | 바닥 가까이에서 위를 바라보고 벽 수직선 유지 | 로우앵글 아키텍처럴 |

통합 과정에는 다음 설계 판단이 포함된다.

- 에디토리얼 텔레포토를 기본에 통합하면 눈높이 정면은 유지되며, 85–135mm 망원 압축과 배경 흐림은 필수 조건에서 빠진다.
- 고감도 클로즈업을 디테일에 통합하면 소재에 접근하는 의도는 유지되며, 매크로의 극도로 얕은 심도는 필수 조건에서 빠진다.
- 라이프스타일과 와이드 환경샷을 공간 포함으로 통합한다. 기존 공간을 유지한다는 전제에 따라 새 스타일링 지시는 덜어내고, 방 전체를 담는 24–35mm 광각 지시는 일반화한다.
- 리버스는 방 반대편으로 이동해 배경과 시점이 달라지는 지시가 있어 45도와 구분한다.
- 기본에 정면·눈높이를 적용하는 것은 기존의 모호한 히어로·피드 지시를 구체화한 제안이다.

## 비율 후보 6개

| 비율 | 현재 서버 요청 크기 |
|---|---|
| 1:1 | 1024×1024 |
| 3:4 | 1152×1536 |
| 4:5 | 1024×1280 |
| 9:16 | 1152×2048 |
| 16:9 | 2048×1152 |
| 3:2 | 1536×1024 |

기존 앵글 변주의 실제 요청 동작을 반영해 `original`을 3:2로 표기한 안이다. 입력 이미지의 실제 비율을 동적으로 유지하는 기능은 이 분류에서 정의하지 않았다.

| 세트 | 컷 | 용도 | 구도 | 비율 |

| 상세페이지 | 디테일 컷 | 일반 이미지 | 디테일 | 1:1 |
| 상세페이지 | 공간 연출 컷 | 일반 이미지 | 공간 포함 | 16:9 |
| SNS | 피드 | 일반 이미지 | 기본 | 1:1 |
| SNS | 세로 피드 | 일반 이미지 | 공간 포함 | 4:5 |
| SNS | 스토리 | 스토리 | 기본 | 9:16 |
| SNS | 광고용 | 배너 | 기본 | 1:1 |
| 광고 | 배너 와이드 | 배너 | 기본 | 16:9 |
| 광고 | 배너 세로 | 배너 | 기본 | 9:16 |
| 광고 | 썸네일 | 썸네일 | 기본 | 1:1 |
