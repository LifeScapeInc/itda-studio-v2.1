## 공통 디자인

36px 상단 바와 프로젝트 탭, 54px 활동 표시줄 / 202px 펼친 메뉴, 메뉴 그룹 사이 구분선, 흰 패널과 8px 간격, 기존 ITDA 색상 및 Noto Sans KR 타이포를 사용한다. 생성 설정 패널의 기본 너비는 342px이며 기존 패널 크기 조절 기능을 유지한다.

가져오기, 프로젝트, 무드보드, 가구, 북마크, 상세 페이지, 계정, 설정, 로그인에도 공통 내비게이션·타이포·표면·컨트롤 스타일을 반영했다. 기존 라우팅, 프로젝트 저장, 데이터 조회, 업로드와 상세 페이지 제작 흐름은 유지한다. 상세 페이지의 재료는 제품 이미지와 의뢰 요청서이다.

## 생성 설정

`BatchEntry`는 직접 설정한 생성 또는 프리셋이다. 직접 생성은 용도 / 구도 / 비율과 수량을 가진다. 프리셋의 수량은 세트 반복 횟수이며, 펼쳤을 때 구성만 읽기 전용으로 보여준다. 생성·프리셋 추가, 개별 삭제, 전체 삭제, 목록 접기와 전문가 설정 접기를 지원한다.

- 프롬프트의 19개 블록은 `generation-option-prompts.md`에서 가져온다. 레퍼런스가 없을 때 공통 앞 문구 → 용도 → 구도 → 비율 → 공통 뒤 문구 순서로 조합한다.
- 프리셋 매핑은 `generation-preset-decomposition.md`의 템플릿 표를 따른다. 앵글 변주는 다섯 설정을 한 프리셋으로 묶고 모두 3:2를 사용한다.
- 기존 레퍼런스 교체·분위기·소재 모드와 전문가 설정은 보존한다. 레퍼런스를 넣은 경우에는 기존 입력 이미지 관계를 적용하여 동일 공간 재촬영 전제와 충돌하지 않게 분기한다.
- 품질별 크레딧은 기존 `QUALITY_COST`를 사용한다. 수량은 행당 1–20이며, 이미지별 요청을 기존 제한된 동시 실행 큐로 처리한다.
- 생성 목록은 프로젝트별 작업 상태에 보존되고 결과 메타데이터에도 저장한다. 이전 히스토리의 설정 재사용도 지원한다.

히스토리와 추가 디렉션은 하단의 히스토리 / 프롬프트 탭으로 나뉜다. 최종 프롬프트 버튼은 생성 설정 패널 안에 있으며 프롬프트 모달은 생성별 탐색과 실제 전송할 문구를 보여준다. 레퍼런스 DB 모달은 가구 / 무드보드 / 북마크 탐색기와 사진 갤러리로 구성한다.

## 평가

완료된 결과 사진을 직접 선택하기 전에는 `선택된 생성물이 없습니다`를 표시한다. 선택한 상태에는 종합 점수 및 Fidelity 게이지를 표시하되 점수는 `— / 100`, 게이지는 평가 대기 상태이다. 결과 생성·히스토리 복원 시 자동으로 사진을 선택하지 않는다. Escape로 결과 선택을 해제할 수 있다. 평가 API는 호출하지 않는다.

## 검증

`node scripts/test-generation-batch.mjs`는 문서 블록 일치, 168가지 조합, 프리셋 구성, 수량과 ID, 레거시 호환, 전문가 설정, 프로젝트 전환, 목업 요청·북마크·히스토리 복원·설정 재사용을 검증한다. 실제 유료 생성 API는 사용하지 않는다.

브라우저 도구가 현재 Windows 브라우저 URL을 확인하지 못해 라이브 화면과 포인터 동작의 최종 시각 검증은 수행하지 못했다. 타입·lint·프로덕션 빌드와 로컬 기능 테스트로 검증했다.
